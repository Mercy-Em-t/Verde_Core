1. Data Storage Design

Translates the Phase 2 Logical 3NF ERD into a physical PostgreSQL implementation.

CREATE TABLE TBL_RCV_LINES ( ReceiptID UUID NOT NULL, SKUID VARCHAR(32) NOT NULL, QtyReceived INT NOT NULL CHECK (QtyReceived >= 0), StatusFlag VARCHAR(15) DEFAULT 'MATCHED', PRIMARY KEY (ReceiptID, SKUID), CONSTRAINT fk_receipt FOREIGN KEY (ReceiptID) REFERENCES TBL_RECEIPT(ReceiptID) ); -- Indexing Strategy CREATE INDEX idx_rcv_sku ON TBL_RCV_LINES(SKUID);

3. Program Specifications

Language / Framework: Node.js (TypeScript 5.x) using Express.

Transaction Rules: All multi-table updates (e.g., updating Inventory Balances and Audit Logs simultaneously) must be strictly wrapped in PostgreSQL BEGIN ... COMMIT; blocks. If any step fails, ROLLBACK must be executed to prevent data corruption.

Code Contracts: Engineers must strictly adhere to the explicitly defined JSON payloads and HTTP Status Codes defined in the Master API Endpoint Specification artifact.
