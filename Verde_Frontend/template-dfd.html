Modeling Protocol

Strict Decomposition Rule

As per standard operational protocol, each decomposition into a lower level (e.g., Level 1, Level 2) must be explicitly executed for each individual subsystem defined in the Level 0 diagram.

1. Context Diagram

Defines the absolute system boundary. Identifies external entities (Actors) and the gross data payloads flowing into and out of the black box (System 0.0).

2. Level 0 DFD

Cracks open the Context black box. Reveals the primary high-level processes (1.0, 2.0, 3.0) and the primary Data Stores (D1, D2). Ensures all external flows from the Context diagram are accounted for.

3. Level 1 DFDs

Cracks open a specific Level 0 process (e.g., Process 2.0 becomes 2.1, 2.2, 2.3). You must generate one Level 1 diagram for every single process bubble in Level 0. This is where Exception Flows from the Use Cases are visually modeled.
