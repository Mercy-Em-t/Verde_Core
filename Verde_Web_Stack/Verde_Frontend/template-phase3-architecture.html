Database Software: Managed AWS RDS PostgreSQL 16 (Multi-AZ).

Terminal Hardware: Zebra TC21 Rugged Android Scanners (Wi-Fi 6 / 4G LTE fallback).

3. Comprehensive Security Plan

Edge / Transport: Cloudflare WAF, Strict TLS 1.3 only. All payloads encrypted in transit.

Authentication: OAuth 2.0 / JWT. Role-Based Access Control (RBAC) enforced at the API Gateway layer.

Data at Rest: AWS KMS AES-256 encryption on all RDS volumes and S3 buckets.

Auditability: Immutable cryptographic hash ledger for all physical inventory mutations (Append-Only).
